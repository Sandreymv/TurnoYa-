# TurnoYa

Sistema virtual de turnos y filas. Proyecto Integrador I, Ingeniería de Sistemas — Universidad del Valle, Sede Tuluá.

## Contenido

La carpeta [`proyecto_integrador`](proyecto_integrador) contiene el sitio web:

- `index.html` — Inicio
- `nosotros.html` — Nosotros
- `objetivos.html` — Objetivos
- `avances.html` — Avances
- `contacto.html` — Contacto
- `css/style.css` — Estilos propios
- `js/main.js` — Interacciones y validación del formulario
- `img/` — Banner e imágenes del equipo

## Cómo verlo

Abre `proyecto_integrador/index.html` en el navegador o sirve la carpeta con una extensión como **Live Server** de VS Code.
