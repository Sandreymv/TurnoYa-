# TurnoYa

Sistema virtual de turnos y filas. Proyecto Integrador I, Ingeniería de Sistemas — Universidad del Valle, Sede Tuluá.

## Contenido

La carpeta [`proyecto_integrador`](proyecto_integrador) contiene el sitio web:

- `index.html` — Inicio
- `nosotros.html` — Nosotros
- `objetivos.html` — Objetivos
- `avances.html` — Avances
- `contacto.html` — Contacto
- `css/style.css` — Estilos propios
- `js/main.js` — Interacciones y validación del formulario
- `img/` — Banner, logo e imágenes del equipo (todo en WebP)

## Guía visual (Actividad 2: Tipografía y color)

La justificación de la tipografía, la paleta, el logo y el slogan, con capturas de **antes y después**, está en [`docs/guia-visual.md`](docs/guia-visual.md).

- **Tipografía:** Poppins (primaria, títulos) + Inter (secundaria, texto)
- **Paleta:** índigo `#3333AF` como color de marca + ámbar `#FFB020` como acento ([ver en Coolors](https://coolors.co/3333af-2a2a8f-ffb020-ececf9-f7f7fc-1e1e2e-555b6e))
- **Slogan:** *Haz la fila sin estar en ella.*

## Cómo verlo

Abre `proyecto_integrador/index.html` en el navegador o sirve la carpeta con una extensión como **Live Server** de VS Code.
